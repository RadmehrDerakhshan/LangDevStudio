# Lang Dev Studio
## Short Explain
Lang Dev Studio is a small engine for Making interpreter. You must be learned a bit python and regex. make interpreter without coding!
## Requirements
python 3.12+

PyQt6
## Run
```bash
pip install -r requirements.txt
python main.py
```
